# Hotel Booking

FastAPI + SQLAlchemy + SQLite + Jinja2. Сеть из 3 отелей и 197 номеров (демо-данные).

## Возможности

- регистрация, вход, выход, личный кабинет с бронями и их отменой;
- **Главное** — поиск свободных номеров по датам/отелю/числу гостей, информация об отелях;
- **Номера** — карточки, фильтр по отелю и количеству комнат, сортировка, пагинация;
- **О нас** — ценности (24/7, тишина и чистота, удобные локации), отели;
- контакты и ссылки на приложение — в футере каждой страницы;
- серверная валидация: даты, существование номера, **пересечение броней** на один номер.

## Структура

```
main.py        маршруты, валидация
database.py    подключение к SQLite
models.py      User, Hotel, Room, Booking
security.py    хеширование паролей (PBKDF2)
seed.py        демо-данные: 3 отеля, 197 номеров
templates/     Jinja2-шаблоны
static/        CSS
```

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Откройте http://127.0.0.1:8000

> Схема БД изменилась. Если остался файл `hotel.db` от прошлой версии — **удалите его**
> перед запуском, база создастся заново.

## Настройка

- `SECRET_KEY` — ключ для подписи сессий. В продакшене задайте свой:
  `export SECRET_KEY="длинная-случайная-строка"`.
- Названия отелей, адреса, телефоны и ссылки на приложение — демо-данные.
  Меняйте в `seed.py` (отели) и `CONTACTS` в `main.py` (футер).
